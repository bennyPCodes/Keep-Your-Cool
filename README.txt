KEEP YOUR COOL - installable iPad version

1. Upload all of these files to any HTTPS web host, for example a GitHub Pages repository.
2. On the iPad, open the page in Safari.
3. Tap Share, then Add to Home Screen.

It opens full screen from the home screen icon. After the first visit it works without internet
(the fonts fall back to system fonts if they were never downloaded).

To change questions, edit the ROUNDS and FINAL lists near the top of the script in index.html,
then bump the CACHE name in sw.js (for example keep-your-cool-v2) so iPads pick up the change.
